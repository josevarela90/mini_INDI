# Resultados

`processed/` contiene CSV derivados de los logs y `raw/` conserva los dos logs principales de la campaña. El manuscrito utiliza `pruebas_detalladas.csv` como fuente de los cálculos de latencia y `tasas_exito.csv` como contraste de tasas.

No se incluye el corpus crudo de voces del desarrollo del wake word por privacidad. Tampoco se publican credenciales de red.
