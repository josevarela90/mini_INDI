# Licencia pendiente de selección

Este paquete se entrega como borrador de repositorio para publicación. **No se asigna automáticamente una licencia abierta**, porque esa decisión corresponde a los autores y a la institución titular de los derechos.

Antes de publicarlo en GitHub se recomienda definir, con autorización institucional cuando aplique:

- licencia de software (por ejemplo, MIT/BSD/Apache-2.0), y
- licencia de documentación/datos (por ejemplo, CC BY 4.0).

Hasta que se incorpore un archivo `LICENSE` explícito, no debe asumirse permiso de reutilización más allá de lo permitido por la ley aplicable.
